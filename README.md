# Nanda Kishor — Personal Portfolio

A modern personal portfolio website with 3D animations, built from resume data.

## Tech Stack

- **React** + **TypeScript** + **Vite**
- **Three.js** / **React Three Fiber** — 3D hero scene with floating shapes, particles, and stars
- **Framer Motion** — scroll and entrance animations
- **Tailwind CSS** — styling with glassmorphism and gradient accents

## Getting Started

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Sections

- **Hero** — 3D animated background with intro and social links
- **About** — Profile summary and quick stats
- **Experience** — TCS and Brototype roles
- **Education** — MCA and BCA
- **Skills** — Backend, Frontend, Databases, DevOps, AI/ML
- **Projects** — Exel, RAGTutor, Timezone
- **Certifications** — Docker Essentials, Core Java (TCS)
- **Contact** — Email, phone, location, social links
